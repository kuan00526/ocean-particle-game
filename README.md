# 洋流粒子遊戲

以台灣周邊海域（東經 118.2–128.2°、北緯 19.8–29.8°）的表層流場為基礎的小遊戲。

## 模式
- **選擇題**：看洋流與 FTLE 色圖，猜青色粒子是從哪個編號出發。
- **落點預測**：只給一個起點，點地圖上你認為粒子會經過的位置，依與漂流路徑的最近距離計分。

## 資料
- 流場：ASCAT 衛星風場推算的 Ekman 表層流（2025-08-12），缺值已補齊，每關會小幅隨機調整。
- 海岸線：由 coasts.mat 簡化而成，只保留台灣本島與中國大陸。

## 使用
直接開啟 `index.html` 即可，或用 GitHub Pages 發佈（Settings → Pages → Deploy from a branch → main / root）。
